# SP / SB / SD 广告费用自动归属

本模块把“识别推广商品”和“核对实际花费”分成两步。活动名称、广告归因销售额、平均比例和人工逐条绑定都不参与自动归属。

## 当前数据流

1. 以所选店铺 SID、站点日期、`profile_id` 和 `campaign_id` 建立活动键。
2. 活动报表 cost 只作核对总额。SP/SD 使用商品广告报表行；SB 可使用经验证的 ASIN 分摊行，或使用商品广告目录关联广告组实际花费。
3. 商品标识只接受本地产品表现映射中的 MSKU 和 ASIN 精确匹配。Ad ID、Ad Group ID、Campaign ID 用于限制记录关系，不能单独推断 SKU。
4. 若同一报表行的 MSKU 与 ASIN 指向不同 local SKU、任一标识重复指向多个 SKU、记录跨 SID、成本重复或成本来源不明确，该行不自动归属。
5. 活动总额与其唯一明细粒度的 cost 逐活动核平。活动报表不加到商品/广告组费用上。某活动不平时只隔离该活动，其他已核平活动仍可在预览中显示。
6. 缺少商品记录不是 0。只有接口明确返回商品级 `cost=0` 才显示 0。未知归属、查询失败、成本不平和未映射分别显示。

金额运算使用 `Decimal`。一个 local SKU 可具有多个 MSKU、ASIN；历史别名仅在其有效日期经过核验时使用。当前产品表现接口返回的别名集合没有提供逐日有效期，因此 UI 会将自动匹配标为预览，不能作为正式周报广告输入。正式写入还需验证日期时区、币种、覆盖范围和真实后台总额。

## SP

使用 SP 商品广告报表的商品行 cost，先按 `profile_id + campaign_id + report_date` 与活动报表核对，再按真实 MSKU/ASIN 映射 local SKU。活动名称和广告成交归因销售额不会改变费用归属。活动行不重复加到商品 cost。

## SB

现有 SB 活动和广告组报表没有商品标识，只能核对活动/广告组总额。归属引擎已经提供两条受控路径：

- **独占广告组路径：** 官方商品广告目录能证明覆盖完整；每条记录能按真实广告/广告组/活动 ID 关联到被推广 ASIN 或 MSKU；同一广告组所有推广商品都唯一映射到同一个 local SKU；广告组 cost 与活动 cost 核平。符合这些条件时，按广告组自己的实际 cost 自动归属。一个广告组推广多个本地 SKU 时，整组留为未归属。
- **官方已分摊金额路径：** 仅当官方 Schema 证明 `spends` 是按 ASIN/SKU 分摊后的金额，并说明 `percent`、舍入、汇总和日期口径，且该结果能与活动实际 cost 核平，适配器才可将它作为经过验证的 SKU 级金额传入。不得把原活动总 cost 乘未经核验的 percent。

以下三个接口尚未接入：

- `POST /pb/openapi/newad/hsaProductAds`
- `POST /pb/openapi/newad/sbDivideAsinReports`
- `POST /pb/openapi/newad/sdProductAds`

云端请求官方文档域名收到网络代理 HTTP 403，当前没有这些页面的完整 Markdown Schema。因此尚不确认它们的具体请求字段、响应 envelope、分页方式、ID 关系、ASIN 列表是否完整、SB 视频广告是否覆盖、`spends` 与 `percent` 的准确语义、币种以及日期时区。不得据接口路径自行推导字段。

## SD

现有 SD 商品报表本身包含 `ad_id`、`campaign_id`、`ad_group_id`、MSKU、ASIN 和 cost，可按精确商品身份匹配并与活动 cost 核对。用户指定的 `sdProductAds` 应作为实际推广商品目录/ID 关系核验层；在拿到 Schema 前，不会假设其字段、历史有效期或覆盖行为，也不会用其结果覆盖报表中矛盾的身份信息。

## 当前 Windows 预览验收

使用 `EX-shop-US`，输入 `ex3114`，日期 `2026-08-29`：

1. 先确认本机分支包含 `amazon_weekly_report/ad_attribution.py`，启动 GUI，刷新店铺，选择 EX-shop-US。
2. 录入 `ex3114`，日期填 `2026-08-29` 至 `2026-08-29`，执行广告费用预览。
3. 分开记录本地参数校验、每个 OpenAPI HTTP/业务 code 状态、是否返回真实活动/商品/广告组行，以及 SP/SB/SD 每日活动总额和唯一明细总额是否核平。
4. 比对领星后台 SB 专属花费 `$19.21`。确认查询到的商品广告/分摊数据能通过真实 ASIN、SKU 和活动关系到达 `ex3114`；不能用 synthetic test 的金额作证明。
5. 若仍显示 SB 未归属，只需要反馈脱敏字段结构、工具/接口名、分页总数及失败阶段，不要发送凭证、Token、Seller ID、广告 ID、订单明细或完整响应。

真实 ex3114 验收之前，当前费用仍只用于预览，不进入 Excel。验证完成后还需在正式接入前确认当前 ASIN/MSKU 映射覆盖历史广告商品变化，并完成 SB 视频广告及日期/币种核对。
